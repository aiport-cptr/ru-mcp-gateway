# Планы

## 0.2 — эксплуатация ✅
- Миграции Alembic вместо `create_all`
- Фоновая очистка истёкших записей
- Ограничение частоты запросов на `/register`, `/authorize`, `/mcp`

Отложено: общий счётчик лимитов (Redis) для нескольких реплик; удаление неиспользуемых
зарегистрированных клиентов.

## 0.3 — права на ресурсы ✅

Перенесено в 0.4: Яндекс 360 от имени пользователя; фильтрация связанных задач в карточке Трекера;
группы пользователей (сейчас права выдаются на роль или на конкретного человека).
