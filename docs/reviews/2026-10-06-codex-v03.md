# Разбор проверки 0.3 от 6 октября 2026

Проверка: Codex, снимок `8a04d8a` (0.3.0). Отчёт — комментарий к коммиту `c2f64d3`.
Исправлено в 0.3.1.

Итог проверки: исправления 0.2.1 подтверждены; в модели прав, `guarded` и проверках ресурсов
коннекторов обходов не найдено. Две находки P2 — гонки в хранилище токенов Яндекса.

| # | Находка | Решение | Тесты |
|---|---|---|---|
| 1 | Обновление токена, завершившееся после `users disable`, создавало удалённую запись заново | Обновление по refresh больше не создаёт запись: только условный UPDATE существующей. Вход сохраняет токены, только если пользователь не заблокирован, держа блокировку строки пользователя (`SELECT … FOR UPDATE`) | `test_review_v03_disable_during_refresh_does_not_restore_credentials` (проверяющего), `test_refresh_after_delete_raises_and_does_not_recreate`, `test_save_refuses_disabled_user`, `test_pg_login_save_waits_for_concurrent_disable` (только PostgreSQL) |
| 2 | Старое обновление затирало токены нового входа | Поколение записи (`user_credentials.generation`, миграция `0005`); результат обновления пишется только если поколение не изменилось с момента чтения (CAS). При конфликте результат отбрасывается, вызов получает актуальный токен | `test_review_v03_relogin_during_refresh_keeps_new_login_credentials` (проверяющего), `test_refresh_caller_gets_new_login_token_after_conflict`, `test_two_processes_refreshing_keep_single_consistent_chain`, `test_generation_increments` |

Корректность больше не зависит от `asyncio.Lock`: он остался только чтобы в одном процессе
не ходить в Яндекс дважды. Тест с двумя экземплярами хранилища (как два процесса) это проверяет.

Тесты проверяющего перенесены в репозиторий без изменения логики:
`tests/test_review_v03_regressions.py`, `tests/test_review_regressions.py`.

Мутационная проверка: удаление условия по поколению роняет 2 теста; удаление проверки
блокировки при входе — 1 тест.

## Предложение проверяющего, принято в план

Стабильные коды ошибок шлюза и correlation ID в ответах коннекторов — для диагностики без
возврата сырых ответов внешних систем (см. ROADMAP, 0.4).
