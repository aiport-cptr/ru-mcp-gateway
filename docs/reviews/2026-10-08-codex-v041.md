Проверено: SQLite — все тесты; PostgreSQL 16 — все тесты, включая блокировки строк.

Мутационная проверка (9 изменений кода, каждое должно ронять тесты): сравнение по провайдеру
вместо версии (оба хранилища), отсутствие новой версии при записи, кэш без сверки версии, сверка
без ротации, использование ответа при конфликте, формат даты, совпадение пустой версии — все пойманы.
Отключение отдельной проверки «записи нет» перед кэшем — эквивалентная мутация: тот же
`RELOGIN_REQUIRED` возникает при чтении записи.
